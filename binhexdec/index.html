BinHexDec

A programmer's calculator for iPhone and iPad.

BinHexDec works with binary, octal, decimal and hexadecimal values together, so you can enter a number in one base and see it in the others at the same time. Alongside ordinary arithmetic it provides the programmer-oriented operations you tend to reach for when working with bits, masks and memory addresses.

Features

  • Binary, octal, decimal and hexadecimal input and display
  • Values shown across all four bases together
  • Programmer-oriented operations for working with bits and integers
